What is LifeTracker

A memory for every life you live in DayZ

Most DayZ lives end quietly: a death, a respawn, and the story is gone. LifeTracker changes that by quietly recording where you went, then giving you back a map of the journey after you die.

What it records

Your position over time during one character's life, from spawn to confirmed death, plus a death-cause classification when the evidence supports one.

What you get back

A private, shareable link to an interactive map of that life's route, with a scrubbable timeline and your in-game name and survival time.

Why server owners like it

Zero setup for players, no accounts, no performance impact beyond lightweight background sampling, and a feature your community can't get anywhere else.

Privacy and data

What's collected, and what isn't

What's collected

  • Timestamped position samples during one character's life.
  • Your in-game name, captured once at the start of that life (not re-checked if you rename mid-life).
  • A death-cause classification when the evidence supports one, otherwise labeled "Unknown."
  • Life duration and start/end positions.

What's never collected

  • Chat or voice content.
  • Inventory contents.
  • Your raw Steam/platform ID in anything public. Internal identifiers are hashed and never exposed through the public link.

Who can see a record

Anyone holding a record's private link can view it, the same way an unlisted video link works. Records are never listed publicly or indexed by search engines. Links are revocable.

Retention and deletion

Completed life records are kept until deleted. Records that never reach a completed state (e.g. the server crashed mid-life) expire automatically after 30 days.

Current limitation: deletion requests go through your server owner or the project directly; there is no self-service "delete my record" button yet.

Opting out

Tracking is opt-in at the server level; it only runs where the server owner has installed and enabled it.

Current limitation: there is no individual player opt-out yet. An in-game command is planned (see the Roadmap), but today, if your server owner has LifeTracker enabled, your life is tracked while you play there. We're flagging this directly rather than overstating what's built.

Server performance

Will this affect my server?

It's designed to be lightweight, but formal load testing at scale hasn't happened yet. Here's exactly what's measured versus assumed.

Honest status: the project targets 60–100 concurrent players, but no formal server-cost profiling has been run at that scale yet. The mod has been confirmed working end-to-end on a real production server with real deaths, but a per-player-count resource table isn't available, since we didn't want to publish invented numbers. This will be updated once real measurements exist.

Installation

Setting up LifeTracker on your server

LifeTracker is currently a closed, manually-onboarded beta; there's no self-service signup yet. The steps below are the real technical process once you're onboarded.

Getting a credential: during this beta, server credentials are issued manually by the project; there's no automatic sign-up page yet. Reach out via the links below to get set up.
1

Install the server-side mod

Load the LifeTracker server mod on your DayZ dedicated server (via -serverMod= or your host's server-mods folder, depending on how you manage mods).

2

Install the client mod (optional)

The companion client mod adds a one-click "Copy Link" button on the death screen. It's published to the Steam Workshop so players auto-download it if your server requires it. Tracking itself works without it.

3

Create your config file

Create config.json in the mod's profile directory with the API endpoint and the credential issued to you:

{
  "apiBaseUrl": "https://<your-issued-endpoint>",
  "webBaseUrl": "https://<your-issued-endpoint>",
  "serverCredential": "<your-issued-credential>"
}

This file is never committed anywhere and should be kept private; treat the credential like a password.

4

Start your server and verify

Boot your server and check its log for a LifeTracker startup line confirming the mod loaded and connected. Run one test life (spawn, move around, die) and confirm a link is produced.

5

Troubleshooting

If the mod logs a fatal error at boot, double-check config.json exists in the right profile folder and that the credential matches exactly what was issued. The mod intentionally fails loudly rather than tracking silently with a broken config.

6

Updating and uninstalling

Update by replacing the mod files with a newer release when one is published. Uninstall by removing the mod from your load line/folder; no separate cleanup step is required on your server, and existing records remain reachable by their links.
